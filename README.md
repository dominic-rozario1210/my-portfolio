# Dominic Rozario — Premium 3D Developer Portfolio

A modern, high-performance developer portfolio built with the **Obsidian Matrix × Spatial Bento** design system.

![Portfolio Preview Banner](public/preview.png)

## Tech Stack (100% Free & Open Source)
* **Framework:** [Next.js 14+ (App Router)](https://nextjs.org/)
* **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) with custom glassmorphism & dark-mode OLED tokens
* **3D Visuals:** [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber) (100% procedural geometry, zero heavy asset downloads)
* **Motion:** [Framer Motion](https://www.framer.com/motion/) for silky smooth section reveals and layout transitions
* **Icons:** [Lucide React](https://lucide.dev/)

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

## One-Click Deployment (Free)
This project is fully optimized for free static/serverless hosting on **Vercel** or **Netlify**:
1. Push this repository to your GitHub account (`https://github.com/dominic-rozario1210/portfolio`).
2. Import the repository into [Vercel](https://vercel.com).
3. The build command `npm run build` will deploy your portfolio with instant global CDN distribution.
